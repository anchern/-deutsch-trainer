# Deutsch Trainer

Німецько-український тренажер слів, який можна розмістити на GitHub Pages або будь-якому статичному хостингу. Без облікових записів, бекенду, бази даних і зовнішніх бібліотек у браузері.

## Що всередині

- **Mit Bus und Bahn** — 45 попередніх слів зі сторінки 76, включно з поясненнями артиклів.
- **Unsere neue Wohnung** — усі 49 слів і виразів зі сторінки 84: пошук житла, нова квартира, дієслова. Українські переклади, контекстні пояснення та приклади для 12 дієслів.
- 94 записи у двох темах, **93 унікальні слова**: Stadtzentrum має спільний ідентифікатор і прогрес.
- Навчання окремої теми, її частини або всіх тем разом. Видимі кнопки режимів замість випадаючих списків.
- Картки в обох напрямках, вибір перекладу в обох напрямках, артиклі, написання, німецька вимова через системні голоси.
- Інтервальне повторення, денний ліміт нових слів, призупинення окремих слів, словник із пошуком.
- Локальний прогрес, автоматичне перенесення старого `busbahn-progress`, експорт та імпорт JSON.
- Офлайн-копія застосунку після першого успішного завантаження. Оновлення застосовується після закриття всіх старих вкладок.

## Запуск і перевірка

Потрібен Node.js 22 або новіший. Залежностей немає, `npm install` не потрібен.

```sh
npm test
npm run build
npm run preview
```

Відкрийте `http://127.0.0.1:4173`. Для редагування вихідних файлів: `npm run dev`. Після зміни файлів оновіть сторінку. Якщо вже встановлено офлайн-копію, після `npm run build` закрийте всі вкладки сайту та відкрийте знову; для розробки також можна вимкнути service worker у DevTools.

`file://` не підтримується: словники завантажуються через `fetch`, тому потрібен звичайний статичний HTTP-хостинг. Локальний сервер зі скрипта призначений лише для перегляду на вашому комп’ютері.

## Публікація і поширення

`npm run build` створює готовий статичний сайт у `dist/` і оновлює `sw.js` у корені. Завантажте **вміст `dist/`** на статичний хостинг. Постійний сервер застосунку не потрібен.

Для GitHub Pages можна зберегти поточний спосіб публікації з кореня гілки: у репозиторії вже є всі потрібні файли. Перед комітом завжди виконуйте `npm run build` та включайте оновлений `sw.js`. Відносні шляхи підтримують адресу репозиторію з префіксом, зокрема `/-deutsch-trainer/`.

CI у `.github/workflows/check.yml` перевіряє словники, тести, складання та актуальність `sw.js`; також зберігає артефакт `deutsch-trainer-static`. Автоматична публікація й налаштування GitHub Pages цим workflow не змінюються.

Другові достатньо надіслати адресу сайту: у його браузері буде власний незалежний прогрес. Для офлайн-режиму потрібен HTTPS (або localhost). Вимова залежить від установлених голосів, деякі з них працюють лише онлайн.

**Зберігайте адресу сайту:** browser storage прив’язане до origin (протокол + домен + порт), а не до GitHub-репозиторію. При перенесенні сайту на інший домен спочатку експортуйте прогрес. Ключ прогресу спільний для копій цього тренажера на одному origin, навіть якщо вони відкриті за різними шляхами.

## Додавання теми

1. Створіть `data/topics/<topic-id>.json`. Скопіюйте структуру наявної теми або приклад нижче.
2. Додайте `"topics/<topic-id>.json"` до масиву `topics` у `data/topics.json`.
3. Виконайте `npm test` та `npm run build`. Комітьте нову тему, реєстр і оновлений `sw.js`.

Інтерфейс, вибір тем, словник і офлайн-кеш підхоплюють реєстр автоматично. Переписувати код інтерфейсу не потрібно.

```json
{
  "id": "food",
  "title": "Essen und Trinken",
  "uk": "Їжа та напої",
  "description": "Продукти й замовлення в кафе",
  "icon": "book",
  "page": 100,
  "sections": [
    { "id": "drinks", "title": "Getränke", "uk": "Напої" }
  ],
  "words": [
    {
      "id": "wasser",
      "section": "drinks",
      "article": "das",
      "de": "Wasser",
      "uk": "вода",
      "note": "Вчіть разом з артиклем: das Wasser.",
      "example": { "de": "Ich trinke Wasser.", "uk": "Я п’ю воду." }
    }
  ]
}
```

Обов’язкові поля теми: `id`, `title`, `uk`, `sections`, `words`. Для повного відображення також задавайте `description`, `page` та `icon` (`home`, `train`, `book` або `cards`). Для слова обов’язкові `id`, `section`, `article`, `de`, `uk`. `note`, `example`, `accepted` і `plural` — необов’язкові. Усі текстові поля — звичайний текст, HTML не потрібен.

- `id` — **стабільний** ідентифікатор латиницею, цифрами й дефісами. Не змінюйте його після публікації: це ключ прогресу. Виправляти переклад чи пояснення можна без втрати прогресу.
- Якщо те саме слово в тому самому значенні є в кількох темах, використовуйте той самий `id`, `de`, `uk`, `article` і `plural`. Прогрес і повторення тоді спільні. Відмінні значення потребують різних ID, наприклад `stock-floor` і `stock-stick`.
- Для дієслів, прикметників і цілих виразів ставте `"article": null`. У `de` залишайте потрібну форму фрази: `eine Wohnung besichtigen`, `den Müll trennen`.
- Множину на кшталт `die Nebenkosten` позначайте `"plural": true`: вона не потрапить у вправу на рід однини.
- `accepted` — додаткові правильні варіанти написання, наприклад `["WG", "Wohngemeinschaft", "die WG", "die Wohngemeinschaft"]`.
- `legacyKey` потрібне лише для перенесених старих слів. Не змінюйте його й не додавайте до нових тем.
- При вилученні теми з реєстру її прогрес залишається у сховищі й резервній копії; після повернення тих самих ID його можна використовувати далі.

## Як влаштоване повторення

Розклад спирається на принцип інтервального повторення й чотири оцінки з [посібника Anki](https://docs.ankiweb.net/studying.html#answer-buttons). Це **власний спрощений алгоритм**, не реалізація FSRS, не точний SM-2 і не формат колод Anki.

| Оцінка | Нова картка / повторення після помилки | Вивчена картка |
| --- | --- | --- |
| Ще раз | через 1 хв | через 1 хв, перехід до навчання |
| Важко | через 10 хв | інтервал × 1,2, щонайменше +1 день |
| Добре | через 1 день | інтервал × коефіцієнт легкості |
| Легко | через 4 дні | інтервал × коефіцієнт легкості × 1,3 |

Коефіцієнт починається з 2,5, обмежений 1,3–3,5; інтервал — максимум 365 днів. Кнопки показують фактичний наступний інтервал. Помилкова відповідь у вправі дозволяє тільки «Ще раз». Правильну відповідь користувач оцінює за складністю. **Відповідь записується після натискання оцінки**; закриття картки до оцінки не змінює прогрес.

Прострочені картки йдуть першими, від найстаріших. Відомі картки не показуються до `due`. Нові беруться в порядку словника, у межах ліміту на локальну календарну добу. Ліміт (5/10/20/50) спільний для тем, але окремий для кожного режиму. Сесія — до 20 карток; повторення після помилки доступне в наступній сесії, коли мине хвилина. Навчання не блокується очікуванням таймера.

Ключ картки — `wordId::mode`. Є шість незалежних режимів: дві сторони карток, два напрямки тесту з варіантами, артиклі, написання. Вивчення артикля не приховує те саме слово у вправі на написання. Призупинення діє на слово в усіх режимах; повернути його можна зі словника.

## Прогрес і його збереження

- Дані: `localStorage['deutsch-trainer:v2']` із версією схеми, картками, призупиненнями, денними лічильниками й налаштуванням ліміту.
- Перенесення: старі позитивні бали `busbahn-progress` переносяться в `cards-de-ua`: 1–2 бали → повторення через день; 3–4 → через 7 днів. Старий формат не розрізняв навички, тому решта вправ починаються з нових карток. Початкові дані зберігаються.
- Некоректні дані не перезаписуються автоматично. Інтерфейс показує попередження та дозволяє завантажити непрочитані дані.
- Імпорт перевіряє формат до запису й об’єднує картки за новішим `updatedAt`; денні лічильники беруться з більшої історії, а не підсумовуються. Це захист від повторного імпорту, а не точне злиття незалежних історій двох пристроїв. Поточний денний ліміт зберігається; призупинення додаються.
- Зміни з іншої вкладки підхоплюються й завершують відкриту сесію, щоб користувач продовжив зі свіжим розкладом. Це не транзакційна синхронізація: для одночасної роботи на одному пристрої використовуйте одну вкладку.
- Дані браузера можуть бути видалені користувачем або системою. Приватний режим, нестача місця й блокування сховища обробляються з попередженням. Рекомендовано час від часу завантажувати резервну копію.

## Структура

```text
data/topics.json       Реєстр тем
data/topics/*.json     Словники
src/content.js         Завантаження й перевірка даних, варіанти відповідей
src/scheduler.js       Чиста логіка розкладу та формування черги
src/storage.js         Версійний прогрес, міграція, валідація, імпорт
src/app.js             Інтерфейс і навчальні сесії
src/styles.css         Адаптивне оформлення
scripts/build.mjs      Перевірка словників і статична збірка
scripts/sw-template.js Шаблон офлайн-кешу
sw.js                  Згенерований service worker; включати до комітів
tests/*.test.js        Автоматичні перевірки даних, розкладу й прогресу
```
